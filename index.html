Prompt Command Reference

Custom system cheat sheet — flat reference, no frills

COMMAND
DESCRIPTION
DUMP
Output all raw content from a source without filtering, summarizing, or restructuring.
Usage: “Dump the entire conversation so far, unedited.”
PROCESS
Parse input and return structured, organized output ready for downstream use.
Usage: “Process this transcript into labeled speaker turns.”
OPTIMIZE
Improve a prompt, instruction set, or piece of text for clarity, efficiency, and output quality.
Usage: “Optimize this system prompt for a coding assistant.”
REDUCE
Strip a text down to its minimum viable content while preserving all load-bearing meaning.
Usage: “Reduce this brief to under 150 words.”
LOCK
Freeze a definition, rule, or value so it cannot be changed or overridden in subsequent steps.
Usage: “Lock the tone as formal and do not adjust it regardless of later input.”
DIAGNOSE
Identify what is broken, unclear, or underperforming in a prompt, output, or system and explain why.
Usage: “Diagnose why this prompt keeps producing off-topic responses.”
REWRITE
Recast existing content under a new constraint — tone, length, audience, format, or style.
Usage: “Rewrite this executive summary for a non-technical audience.”
COMPARE
Place two or more items side by side and surface meaningful differences and trade-offs.
Usage: “Compare these two system prompts on precision, scope, and edge-case handling.”
CONTEXT INJECTION SUMMARY
Produce a compact, self-contained block of background information formatted to be injected into a new session.
Usage: “Give me a context injection summary of this project so I can paste it into a fresh chat.”
ZIP FILE
Compress an entire conversation, document, or knowledge base into the smallest lossless reference snapshot.
Usage: “ZIP file this thread — I need the smallest version that lets me fully reconstruct the session later.”
HIGH-SIGNAL EXTRACT
Pull only the highest-value, non-redundant information from a larger body of text.
Usage: “High-signal extract the key decisions and blockers from this meeting log.”
OPERATIONAL CORE EXTRACT
Isolate the minimum set of instructions, facts, or rules required to keep a system functional.
Usage: “Operational core extract — what are the five rules this agent cannot run without?”
PORTABLE CONTEXT BLOCK
Build a transferable, session-agnostic block that fully restores working context in any new environment.
Usage: “Generate a portable context block I can drop into ChatGPT, Claude, or a new Copilot session and pick up exactly where we left off.”

End of reference — hosted cheat sheet.
